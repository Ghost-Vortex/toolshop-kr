# Интернет-магазин инструментов «ToolShop»

Клиент-серверное приложение, выполненное в рамках курсовой работы по
дисциплине «Клиент-серверное программирование», вариант 24.

Серверная часть — NestJS (TypeScript), клиентская — React (Vite).
Данные хранятся в оперативной памяти и не сохраняются между
перезапусками приложения, как того требует техническое задание.

## Состав каталога

| Папка | Содержимое |
| --- | --- |
| `DB` | Скрипт создания схемы PostgreSQL и резервная копия базы данных |
| `Source/server` | Серверная часть приложения (NestJS) |
| `Source/client` | Клиентская часть приложения (React) |

Пояснительная записка сдаётся отдельным файлом PDF и в архив не входит.

## Запуск

Требуется Node.js версии 20 или новее.

Серверная часть (порт 3000):

```
cd Source/server
npm install
cp .env.example .env
npm run start:dev
```

Клиентская часть (порт 5173):

```
cd Source/client
npm install
npm run dev
```

После запуска доступны:

* приложение — http://localhost:5173
* программный интерфейс — http://localhost:3000/api
* спецификация OpenAPI — http://localhost:3000/api/docs
* состояние сервера — http://localhost:3000/api/health

## Обязательные конечные точки задания

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/users` | Получение списка всех пользователей |
| `GET /api/users/:id` | Получение пользователя по идентификатору |
| `POST /api/users` | Создание нового пользователя |

Пользователь содержит поля `id`, `name`, `email` и `age`; все поля, кроме
`age`, обязательны, `email` проверяется на соответствие формату адреса
электронной почты.

Пример создания пользователя:

```
curl -X POST http://localhost:3000/api/users \
     -H 'Content-Type: application/json' \
     -d '{"name":"Новиков Пётр Ильич","email":"novikov@example.com","age":28}'
```

## База данных

Приложение работает с данными в памяти. Папка `DB` содержит проектную
схему той же предметной области для PostgreSQL 16: шесть таблиц, три
представления, четыре функции, три хранимые процедуры и шесть триггеров.
Подробности — в файле `DB/README.md`.
